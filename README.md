# avito — бот + HUB BRO + общие данные

```
avito/
├── data/      формат данных (schema/FORMAT.md), сервер данных (server/), данные клиента (store/), дизайн-токены (design/)
├── bot/       бот Авито + приложение менеджера (Flet) + трей — клон teacher57/avito-bot-broxbro
└── hub-bro/   веб-кабинет HUB BRO — клон SimkaDV/HUB-Bro
```

Клиенту ставят: только бот = `data` + `bot`; только хаб = `data` + `hub-bro`; оба = всё. Бот и хаб работают с
данными **только через сервер данных** (`data/server`, порт 8791). Сервер хаба (порт 8790) отдаёт кабинет,
проксирует Авито и `/api/*` → сервер данных.
