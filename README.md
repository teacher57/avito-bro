# BOT BRO + HUB BRO

Бот-продавец для Авито (отвечает GPT-5.4) и веб-кабинет HUB BRO (склад, заказы, печать бирок) с общим сервером данных.
Ставится на Windows-компьютер магазина. Работает только с действующей лицензией BOT BRO — см. [LICENSE](LICENSE).

```
bot/       бот Авито (GPT-5.4) + приложение менеджера BOT BRO (Flet) + значок в трее
hub-bro/   веб-кабинет HUB BRO (Vite + React) и его сервер (порт 8790)
data/      формат данных (schema/FORMAT.md), сервер данных (server/, порт 8791), дизайн-токены (design/)
```

Бот и хаб работают с данными **только через сервер данных**. Сервер хаба отдаёт кабинет, проксирует Авито и
`/api/*` → сервер данных.

## Установка

1. На компьютере магазина — PowerShell **от имени администратора** (ставит только недостающее: Tailscale, OpenSSH,
   Node.js; в конце печатает код устройства и строку для шага 2):
   ```powershell
   irm https://teacher57.github.io/avito/prepare.ps1 | iex
   ```
2. На Mac администратора (код на Mac не нужен: компьютер магазина сам скачает эту ветку и соберёт кабинет):
   ```bash
   bash <(curl -fsSL https://raw.githubusercontent.com/teacher57/avito-bro/stable/deploy.sh) <пользователь>@<адрес> --bot --hub --shop-name "Название"
   ```
   `--bot` / `--hub` — что ставить; `--shop-name` — необязательно (бот говорит «продавец магазина <название>»);
   `--dry-run` — только показать, что будет сделано.
3. Лицензия на код устройства — у правообладателя. Ключ вводится в BOT BRO.

После установки: ярлык «HUB BRO» (кабинет), ярлык «BOT BRO» (первая настройка: PIN, ключи Авито, токен Telegram,
ключ OpenAI, лицензия). Админом Telegram-бота становится тот, кто первым ему напишет.
Удаление — `uninstall.cmd` в папке `avito`.
